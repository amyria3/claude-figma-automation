## Design principles (quick reference)

Full principles: `figma-design-principles-arkadieff.md`; token table: `2-tarabao/2.1-ux-ui-dokumentation-tarabao.md` (section "Design Tokens").

- **All layouts** as `flex-row` / `flex-col` (auto-layout), naming per Tailwind conventions (lowercase)
- **Spacing tokens (px):** 2 / 4 / 6 / 8 / 12 / 16 / 20 / 28 / 40 / 48 / 56 — collections `Lyt scl / Spcngs / Gaps` (`gap-*`) and `Lyt scl / Spcngs / Box Spacing` (`box-spacing-*`)
- **Values between token steps:** fall back to the Tailwind utility scale `Lyt scl / Tailwind-utility-units` (`[twuc]-N`, 1 twuc = 4px). Never leave gaps/paddings hardcoded in masters.
- **Variables:** work via the plugin API (fixed 2026-07-13) — always use the full ID prefix `VariableID:...`; see `1.3-figma-api-reference.md`

## Operations

- **Text:** translate, correct, replace, batch across nodes (font-load recipe first — but only for text mutations, see 1.3 §1️⃣!)
- **Styling:** read & set colors, fills, strokes; bind variables to properties
- **Layout:** flex VERTICAL/HORIZONTAL, alignment, sizing
- **Nodes:** create, delete, rename, nest
- **Validation:** visual check via `get_screenshot` or `await node.screenshot()` (inline); `get_metadata` for structure (hierarchy, counts, positions — returns XML, no images)

## Known constraints

| Feature | Status |
|---|---|
| Variables read/write/create/bind | ✅ works via plugin API (full `VariableID:` prefix required) |
| Text style creation | ✅ local styles via `createTextStyle` (library styles: transfer by ID only, see 1.5) |
| Stylesheet workaround | LEGACY — only for text layers without existing variable binding or library text-style transfer, see `1.5-figma-stylesheet-workaround.md` |
| `figma.notify()`, `console.log()` as output | ❌ use `return` |
| Sync APIs (`getNodeById`, `getLocalVariableCollections`, `getStyleById`) | ❌ use async variants |
| FLOAT variables bound to text, PERCENT leading/tracking as variables | ❌ see 1.3 §1️⃣/§2️⃣ |
