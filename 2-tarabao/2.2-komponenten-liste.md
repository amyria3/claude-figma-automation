# Komponenten-Liste Tarabao

Spalte **Beschreibung**: erklärt kurz, was die Komponente ist/zeigt, inkl. struktureller Anmerkungen.

Spalte **Nutzt Farbschema**: die Farb-Achsen, die in der Komponente wirken — direkt gebundene Variablen, Modus-Pins auf eigenen Frames UND die Achsen der verschachtelten Komponenten (der Modus wird vererbt, die Komponente schaltet mit). `tint` = Color Modes (cole-/purple-tint-surface × warm/snow, Haupttheme); `mc` = Mega-Cards (bunte Kampagnen-Themes, inkl. Buttons LG); `sp` = Special (forest/lilac, z. B. Voucher/Banner); `sm` = single-mode / theme-fix (Filter Panel, Search, Sustainability, NutmixerTags); `–` = keine direkte Farbvariable.


Zweite Zeile unter dem Namen (**↳ *nutzt:***, konsumierte Komponenten als Figma-Links): bei zusammengesetzten Komponenten (alle außer Buttons, Inputs, Primitives) die direkt konsumierten **katalogisierten** Komponenten (eine Ebene; Icons/Hilfsframes ausgelassen; `–` = keine).
