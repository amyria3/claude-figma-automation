## Figma zeigt installierte Schriften nicht an

**Dokumentiert:** 18.09.2026 · **Betrifft:** Figma Desktop 126.x, macOS 26.x, Mac mit mehreren Benutzerkonten

### Symptom

Figma zeigt eigene Schriften nicht mehr in der Schriftenliste, obwohl sie installiert sind und am Vortag noch funktioniert haben. Die geöffnete Datei meldet fehlende Schriften. Weder ein Neustart der App noch ein erneutes Installieren der Schriften hilft.

### Ursache

Figma liest lokale Schriften nicht selbst, sondern über einen Hintergrunddienst, den FigmaAgent. Dieser Dienst belegt einen festen Port am Rechner.

Hat der Mac mehrere Benutzerkonten und bleibt ein zweites Konto per Benutzerwechsel angemeldet, läuft dort ein eigener FigmaAgent weiter. Beide Agents greifen nach demselben Port. Bekommt ihn der Agent des fremden Kontos, liefert er Figma die Schriftenliste jenes Kontos. Schriften unter `~/Library/Fonts` gehören aber zum jeweiligen Benutzer, deshalb fehlen sie dann komplett.

Welcher Agent den Port bekommt, entscheidet sich beim Start. Daher tritt der Fehler sprunghaft auf: an einem Tag stimmt alles, am nächsten fehlen die Schriften, ohne dass sich etwas geändert hat.

### Diagnose

```bash
# 1. Liegen die Schriften überhaupt im eigenen Benutzerordner?
ls -1 ~/Library/Fonts | wc -l

# 2. Laufen Figma-Prozesse unter einem zweiten Konto?
ps ax -o user,pid,lstart,command | grep -E "MacOS/Figma$|figma_agent" | grep -v grep

# 3. Welches Konto ist gerade am Bildschirm angemeldet?
stat -f%Su /dev/console
```

Zeigt Befehl 2 Prozesse unter einem anderen Benutzernamen als dem aus Befehl 3, ist die Ursache bestätigt.

### Lösung

1. Über das Apple-Menü zum fremden Konto wechseln und sich dort **abmelden**. Ein reiner Rückwechsel genügt nicht, die Prozesse laufen sonst weiter.

   Alternative im Terminal, braucht das Admin-Passwort:

   ```bash
   sudo pkill -u <kontoname> -f Figma
   ```

2. Im eigenen Konto Figma beenden, danach den Agent beenden und Figma neu starten:

   ```bash
   osascript -e 'quit app "Figma"'
   pkill -f figma_agent
   open -a Figma
   ```

   Figma speichert laufend in der Cloud, durch das Beenden gehen keine Änderungen verloren.

3. Kontrolle: Die Schriftenliste in Figma öffnen und eine eigene Schrift suchen.

### Vorbeugung

Schriften, die in allen Konten zur Verfügung stehen sollen, nach `/Library/Fonts` legen statt nach `~/Library/Fonts`. Dann findet sie jeder Agent, unabhängig davon, welches Konto den Port gerade hält.

### Abgrenzung

Nicht verwechseln mit dem Font Loading in der Plugin-API (`loadFontAsync`), beschrieben in `1-figma-claude-technical/1.2-figma-workflow-technisch.md`. Dort geht es um Schriften, die Figma serverseitig für die Automatisierung braucht, hier um lokal installierte Systemschriften in der Desktop-App.
